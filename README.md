# Gate_Access_System

A Gate Access System is a biometric security and authentication system that uses computer vision and machine learning techniques to control and monitor entry access. It performs real-time face detection and face recognition through live camera feeds to verify user identity before granting access. The system automates security operations by continuously capturing facial images, preprocessing them, and matching them with trained facial datasets for secure and contactless authentication.

**Tech Stack:** _Python, OpenCV, Haar Cascade Classifier, LBPH Face Recognizer, SQLite, NumPy, Real-Time Camera Integration_

# Project Description

Developed a real-time biometric gate access system using machine learning and computer vision techniques for secure identity authentication. The system utilized Haar Cascade classifiers for face detection and the LBPH algorithm for face recognition to provide automated access control through live camera feeds. The project included dataset collection, preprocessing, face training, real-time inference, and database integration for storing user identities and access records. Continuous image capturing and recognition workflows were implemented to support real-time biometric authentication and surveillance use cases.
